My project is called **SmartPark — Campus Parking Management System**. It is a Python-based application designed to manage parking spaces in a university or college.

The main purpose of this project is to make parking management easier by keeping track of parked vehicles and their assigned parking slots.

The application allows users to park a vehicle, remove a vehicle, search for a vehicle using its registration number, and display all currently parked vehicles.

I developed this project incrementally using Git and GitHub. I started with a basic parking system and then added new features through multiple commits. This helped me understand how version control tracks changes in a program and how GitHub stores the project online.

The project uses Python dictionaries to store vehicle registration numbers and their assigned parking slots. Currently, it is a basic simulation, and the parking records are stored temporarily in memory.
